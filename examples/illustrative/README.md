# Illustrative shader snippets

These snippets show one possible GLSL/WGSL approximation of the
`thin-film-interference` operator. They are implementation sketches for
orientation and review, not normative renderer code and not proof that the
full Airy sum, spectral observer, or energy-conserving transport is present.

The normative contract remains the operator catalog, schemas, and recipes.
Backend implementations must honor the declared slots and the ontology-gap
register before claiming physical fidelity.
